## 6. 队友安装命令

以下命令在 `项目` 根目录执行。先确保本机有 Python 3.11.5 64 位；`py` 是 Windows Python Launcher，若使用 Anaconda，可把第一条换成已核实版本的 `python -m venv .venv`。已有 `.venv` 时直接使用其中的 Python，不需要重新创建。

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r soulband-demo/requirements-lock-win-py311.txt
```

需要跑网页检查时：

```powershell
.\.venv\Scripts\python.exe -m pip install -r soulband-demo/requirements-dev-lock-win-py311.txt
```

需要打包 Windows 时另安装已声明的构建工具（其完整间接依赖本轮未锁定）：

```powershell
.\.venv\Scripts\python.exe -m pip install -r soulband-demo/requirements-build.txt
```

运行库锁定文件包含 **24 个包**，开发锁定文件引用它并补充 **3 个包**。清单按本机已安装元数据及生效的依赖条件生成，已核对安装版本满足声明约束；本轮没有在另一台机器重新安装验证。

这份锁定文件限定 Windows x64 / Python 3.11。两人共同修改依赖后，要重新验证并更新共享清单；不要只在自己环境里执行一次升级。

## 7. 比依赖版本更直接影响互通的约定

1. **同步同一份代码和 API 定义。** 当前宿主版本为 0.5.0，Android 应用仍标 0.4.0，版本号不同不自动表示协议不兼容。接口以宿主 `/openapi.json`、`mobile_api.py`、`pc_api.py` 为准。本次检查时 Git HEAD 是 `31d3cb8`，工作区存在未提交变更，不能把这个提交号当作已包含本轮修复的交付版本；队友只拉取该提交也不一定拿到这些修改。
2. **统一 JSON 字段、枚举和时间单位。** Windows 心跳 `sampled_at` 是 Unix 秒；Android `sampled_at_ms` 是 Unix 毫秒；`sequence` 单调递增。成员身份由配对 Bearer 凭据确定。新增字段与校验要在两端一起核对。
3. **使用同一个宿主和匹配的公有 CA。** 生产联调使用控制台实际地址和 HTTPS 端口 8766。客户端必须信任该宿主生成的公有 CA；每台开发机自己生成的 CA 并不相同，不能把一台宿主的客户端包拿去连另一台不同 CA 的宿主。仅共享公有证书，不共享私钥。
4. **保留协议采样参数。** Windows 默认每 3 秒采样、15 秒过期；Android 每 15 秒尝试采样、90 秒过期；近期操作窗口 60 秒，无操作观察窗口 1200 秒。默认值在 `policy.py`，修改时同步采集端与服务端，不能把 Windows 与 Android 的过期时间合并。

仅统一库版本不能保证两份不同协议、不同 CA 或不同业务分支的程序互通；开发时应把上述约定和版本清单一起共享。
