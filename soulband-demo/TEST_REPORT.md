## v0.1.0 历史记录

日期：2026-10-27。此记录描述实际执行的检查，不代表完整项目已通过验收。

## 环境

- Windows；Python 3.13.13；项目隔离环境 `.venv`。
- FastAPI 0.162.0、Uvicorn 0.54.0、httpx 0.28.1、Pydantic 2.14.1、PySide6 6.12.0。
- 界面检查使用 Playwright 1.64.1 和本机 Microsoft Edge，无头模式。
- 无可用 Ollama，因此未开展真实模型评测。

## 后端检查

命令：`..\.venv\Scripts\python.exe -m unittest discover -s tests -v`。

实际结果：13 项测试通过。测试数据库与正常演示数据库隔离。

1. 草案未全员确认不发送提醒，全员确认后生效。
2. 持续设备活动不重复提醒；修订不绕过同周期限制；跨午夜仍归属同一静音周期。
3. 电脑无操作而手机有操作时判断有活动；缺少必要手机数据时未知。
4. 非静音时段不扩展安静要求。
5. 有效人工状态优先；收件箱只返回所选样例身份的提醒。
6. 未改善反馈允许一次后续提醒，之后转入协商，不继续催促。
7. 已有更新版本时旧草案不能再次确认生效。
8. 金额按整数分分摊且合计守恒；私密输入不进入持久化状态。
9. 模型调用失败返回错误，不切换成模拟结果。
10. 推理期间上下文变化，旧结果不执行。
11. 模型将缺数据推断为休息，结果被拒绝。
12. Ollama HTTP 适配器发送 JSON Schema 并解析结构化回复；此项使用模拟 HTTP 服务，不是真实模型。
13. 公约生效后，后台调度无需手动点击即可完成判断并生成提醒。

初次检查发现 SQLite 连接未显式关闭，已修复并重跑通过。当前测试运行仍会显示依赖方关于 TestClient/httpx 的弃用提示，不影响本次结果。

## 界面检查

命令：`..\.venv\Scripts\python.exe tests/check_ui.py`。

实际结果：9 项检查通过，页面脚本错误 0。结果保存在 `screenshots/ui-check-results.json`。

- 1440 像素宽桌面页面正常呈现。
- 通过界面切换四个身份，逐个确认同一公约。
- 执行活动判断，走通主动提醒链路。
- 收件箱显示提醒并可标记已读。
- 账单表单可提交并显示结果。
- 私密表达表单可生成演示话术。
- 模拟日期时间可更新。
- 390 像素宽手机页面可导航，概览和公约页无水平溢出。
- 无页面 JavaScript 错误。

初次界面测试发现账单输入框的正则转义导致合法金额无法提交，已修复并重跑通过。

## 桌面入口

执行 `desktop.py --smoke-test`，Qt 桌面容器成功加载页面，检查页面正文后保存截图。

离屏测试初次出现图形上下文错误和空白截图，已为离屏检查增加软件渲染设置；再次检查并人工查看截图，确认页面内容正常。离屏环境仍可出现 Qt 图形后端诊断信息，不能据此认定所有显卡环境均已验证。

## 未验证范围

- 真实 Ollama 模型的生成效果、活动判断质量、提醒决策质量和资源占用。
- 原生 Android APK、真实设备事件、Android 后台通知、系统通知送达。
- 多台物理设备的局域网连接、证书、正式鉴权及权限隔离。
- 自动排班、值日互换、临时公约审批及完整 Agent 工具调用。
- 项目方案中的正式基线、独立测试集和优化前后指标对比。

模拟模式的运行耗时不作为真实模型性能数据。手机视口检查不等于 Android 真机验证。
