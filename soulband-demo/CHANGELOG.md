# v0.4.0 · 2026-11-08

- 增加原生 Kotlin 完整业务入口与 Windows 配对成员客户端；支持多电脑分别采样，各成员一个电脑摘要槽。
- 增加局域网成员设备授权、网页身份固定、来源检查、本人更新权限与接收回执。
- 增加局域网 HTTPS 启动与证书续期；双端包含项目公有 CA，正常检查证书链和地址，不静默降级；失效公约旧通知保留历史但不补弹。
- 补齐需求卡和公开范围、模型受控记录/查询、临时安排与到期恢复、公约撤销/截止、排班与互换、参与人分账与结清、协商建议。
- 安装并校验项目隔离的 Ollama 与 Qwen2.5-7B，优化为模型两阶段判断与结构化提醒分支；无模拟回退。
- 提供独立验收库启动入口、安装包、原生与网页检查、真实模型流程检查和可复现探索评价。
- 原方案、旧演示库和旧 APK 保留；真机与多台物理电脑仍需实测。具体证据见本轮交付报告。

# 版本记录

## v0.3.0 · 2026-11-05

- 新增 Kotlin 原生 Android APK，提供连接、授权、状态采集前台服务、收件箱与系统通知。
- 宿主本机生成一次性配对码，手机凭据绑定成员；凭据以哈希持久化，支持解除配对。
- 接收 Android 状态摘要，拒绝过期或重复上报；暂停请求使用递增序号避免旧采样覆盖。
- 区分明确交互、单纯亮屏、短暂锁屏与持续无活动；权限或数据不可用时未知。
- Android 原生来源加入多设备融合，90 秒没有有效数据即未知；已有通知偏好和提醒校验继续生效。
- 增加原生配对设置、固定 APK 下载入口、局域网联调启动脚本和安装说明。
- 40 项后端测试、9 项原界面检查和 5 项配对界面检查通过；APK 构建、Lint 和签名验证通过。

当前无已连接手机，iQOO 12 真机安装、系统授权、锁屏/解锁、Doze、省电和通知显示尚未验证。原生完整公约与公共事务界面仍待实现；原生通知采用前台服务轮询，不是远程推送平台。

## v0.2.0 · 2026-10-27

- 接入宿主 Windows 当前会话的真实输入空闲与锁屏状态采集。
- 增加显式成员绑定、暂停和切回模拟；切换演示身份不改变绑定。
- 展示实测与模拟来源；首次绑定将未接入的模拟手机置为未知。
- 采集失败、暂停、过期时转为未知；短暂无操作和刚锁屏不直接推断休息。
- 真实信号接入现有模型输入、提醒校验和自动判断调度。
- 使用语义上下文签名，防止采样心跳导致模型判断持续失效；状态实质变化仍拒绝旧决定。
- 业务时钟增加实际时间模式，保留原模拟模式。
- 兼容原数据库，升级前创建独立备份，不重置公约和历史数据。
- 完成 25 项后端测试、9 项原界面检查及 7 项真实 Windows 采样与界面检查。

限制：Android 仍为模拟，通知仍为应用内消息；未实测锁屏/解锁的完整切换过程，未在真实 Ollama 模型上评测。真实采集仅代表运行服务的 Windows 当前会话，不代表所有客户端都已自动感知。
