# v0.5.0 · 2026-11-08

- 修复公约到期死锁：到期在存储层统一投影为 `expired` 并清空生效指针，之后可直接加成员或生成新版本；撤销入口提示「公约已到期」。
- 提醒改由宿主机定时器驱动：持久化下次触发时间，进入静音时段起点才判断一次；启动时补发未超过 15 分钟的判断，超时记为「已错过」并写追踪，不补发过期提醒。
- 静音时段每分钟的业务时钟跳动不再触发推理；同一时段重复判断只保留一条提醒，多个条款命中同一成员时合并 `clause_ids`。
- 公约生效不再依赖模型：记录步骤失败时由程序写入受控回执并明确标注降级；模拟模式的失败仍然报错，不静默降级。
- 新增同机四座位演示：宿主本机可签发 7 天座席会话（`/api/demo/seat`），四个浏览器窗口分别以不同成员身份运行；座席不能加成员、改设置或操作设备授权。入口 `../启动四座位演示.cmd`。
- 私密诉求卡改存独立表，不进入共享状态、导出或页面快照。
- `/api/state` 支持 `since` 增量游标，页面空闲时只回填运行时信息；SQLite 开启 WAL 与 `busy_timeout`。
- 新增启动备份与手动备份（VACUUM INTO + JSON 导出）。
- 后端 61 项测试通过（原 52 项 + 新增 9 项）；`.venv` 已在本机建好，`output/` 构建产物仍不在仓库中。PySide6 固定为 6.9.3（6.12.0 在本机导入 QtCore 失败）。
